# Market Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A merchant picks the market they sell into, and the page is written in that market's language carrying the facts that market's shoppers look for before they buy.

**Architecture:** A new sliced skill `60-markets.md` holds one hand-written block per market, read through the same `sliceSkill` helpers `20-patterns.md` already uses. `brief.market` is optional and null by default, so an unset market leaves every prompt byte-identical to today. The market's block is spliced into all three model stages, because each decides something different: which bands exist, what is inside them, and what the words are.

**Tech Stack:** TypeScript strict, zod (`lib/validation.ts`), zustand (`lib/store.ts`), React client components, plain `tsx` assertion scripts for tests.

## Global Constraints

- Branch: `struct-v2`. Do not merge or push.
- `market` is optional, defaults to `null`. `null` must behave exactly as today.
- The twelve ids, exactly: `us uk in cn jp de fr vn id br gulf au`.
- A market block states commercial facts only — language, currency, payment, delivery, returns, trust signals, legal lines, review culture, how much a page is expected to say. **No block describes colour, typography or layout.** Those belong to the visual style the merchant picked.
- Density is a consequence of the facts a market requires, never an instruction. No block may contain a sentence of the form "pages in X are dense".
- An unrecognised market, or one whose block is missing, resolves to `null` and never fails a build.
- Do not modify `20-patterns.md`, `30-verticals.md`, `40-motion.md`, the palette, or the element vocabulary.
- The repo has 3 pre-existing eslint errors (`require()` imports in `lib/design/plan.ts` and `scripts/baseline.ts`). Compare counts; do not assume clean.

# Markets

One block per market, spliced in when the merchant picked one. Everything here
is a COMMERCIAL fact — what a shopper in this market looks for before they

   Markets, without a model.

   The assertion that matters most here is a NEGATIVE one — a brief with no

       npx tsx scripts/test-market.ts

import { createRequire } from "node:module";
import Module from "node:module";

const require_ = createRequire(import.meta.url);
const resolve_ = (Module as unknown as { _resolveFilename: (r: string, ...a: unknown[]) => string })
  ._resolveFilename;
(Module as unknown as { _resolveFilename: unknown })._resolveFilename = function (
  this: unknown,
  request: string,
  ...args: unknown[]
) {
  if (request === "server-only") return require_.resolve("./server-only.cjs");
  return resolve_.call(this, request, ...args);
} as never;

let failures = 0;
function check(ok: boolean, label: string, detail: string | null = null): void {
  console.log(`  ${ok ? "✓" : "✗"} ${label}${detail ? ` — ${detail}` : ""}`);
  if (!ok) failures++;

async function main(): Promise<void> {

  const { sliceSkill, sliceIds } = await import("@/lib/ai/skills");

  const inFile = new Set(sliceIds("markets"));
  for (const id of MARKET_IDS)

  for (const id of inFile)

      `the block "${id}" is a listed market`,
      isKnownMarket(id) ? null : "block exists but no id offers it",

  check(MARKETS.length === MARKET_IDS.length, "every id has a label");

  console.log("\nthe blocks stay commercial");

     merchant actively pressed, and would be the caricature this feature was
     designed to avoid. */
  const banned = ["font-size", "typeface", "saturated", "colour palette", "color palette"];

    check(!hit, `${id} describes no visual style`, hit ?? null);

  console.log("\nvalidation");

  check(isKnownMarket("in"), "a listed market is known");
  check(!isKnownMarket("xx"), "an unlisted one is not");
  check(!isKnownMarket(""), "and neither is nothing");

  console.log(`\n${failures === 0 ? "PASS" : `${failures} FAILED`}\n`);
  process.exit(failures === 0 ? 0 : 1);
}

main().catch((e) => {
  console.error(e);
  process.exit(1);
});
