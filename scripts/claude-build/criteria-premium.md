# What we sell

Each set is sold for **$500**. A merchant pays that to make their store look like a top-tier brand — the kind of site a design agency charges $10,000+ for. If a set would not make a merchant say "this looks expensive" in the first three seconds, it is not finished. When in doubt, cut, refine and polish instead of adding.

# The set

- 7 pages, in this order: Home, Product, Collection, About, Contact, Blog Article, Sale.
- One store, one brand: an invented brand name, a one-line positioning, real-sounding product names, prices and copy for that brand. No lorem ipsum, no "Product name", no generic "Shop now" everywhere.
- Every page belongs to the same brand system (palette, type, spacing, buttons, image treatment, motion) — a merchant must feel it is one site, not 7 templates.

# Every set is different

`existing` lists every set we already have. Before designing, read it and choose:

1. **An industry and concept none of them has.** Not just a new name: a different kind of store and customer. If the batch note names an industry, find an angle inside it that no existing set takes (e.g. not another minimalist skincare — perhaps a botanical apothecary, a men's grooming atelier, a clinical lab-style brand).
2. **A look none of them has.** Pick and write down, before any HTML, one distinct art direction from a range like:
   editorial magazine · Swiss / grid-strict · quiet luxury (ivory, serif, airy) · dark luxe (black, gold or metal, high contrast) · brutalist / raw · retro 70s · Japanese minimal · Scandinavian soft · Mediterranean warm · bold colour-blocking · organic / earthy textures · techno-futuristic · art-deco · handcrafted / artisanal · playful pop.
   Then make it specific: the exact palette (4–6 hex values with their roles), a font pairing (Google Fonts; one display face with character + one readable text face), the button and card shapes, the image treatment (full-bleed, framed, duotone, cut-out on colour…), and one signature layout idea that recurs across the set (an overlapping image grid, a giant typographic hero, a split-screen story, a marquee…).
3. If your choice is close to an existing set's blurb on both concept and look, choose again.
4. Write the industry and the look in the set's `blurb`, so the next build can avoid them.

# Quality bar

- **Hierarchy and rhythm:** generous, consistent spacing on an 8-px scale; clear type scale (display / headings / body / caption); every section has one job and one focal point. Alternate dense and airy sections so a long page has rhythm.
- **Typography:** display headings large and confident; body 16–18 px, line length 60–75 characters, line-height 1.5–1.7. Never more than 2 families.
- **Colour:** restrained — one accent used deliberately. Text contrast at least WCAG AA.
- **Imagery:** consistent, high-quality, on-brand images (same mood, light and crop style across the set); real product shots on product cards. Never a mismatched stock mix.
- **Conversion:** each page still sells. Home: strong hero with one clear CTA, social proof (reviews, press logos, numbers), featured collection, brand story, newsletter. Product: gallery, price, variants, add to cart above the fold on desktop, benefits, details/ingredients/specs, reviews, FAQ, related products. Collection: filters/sort bar, clean grid, a merchandising banner. Sale: urgency (countdown, discount badges) without looking cheap.
- **Details that read premium:** subtle, purposeful motion (fade/slide on scroll, hover states on every link, button and card); refined dividers, eyebrow labels, numbered sections; consistent icon set; nothing default-looking.
- **Mobile is half the buyers:** every section designed for 375 px too — stacked in a sensible order, readable type, tappable buttons, no overflow, no tiny text.
- **Only what PageFly can reproduce** (follow the pagefly-builder rules), and the `.pagefly` must render identically to its HTML.

# Review before upload

Review each page at least 2 rounds as a demanding art director, on desktop and mobile:
- Would this pass as a $10k agency site? Name the 3 weakest things and fix them.
- Is anything generic, crowded, misaligned, inconsistent with the other pages, or off-brand?
- Does it look different from every set in `existing`?
Only upload when the answer to all three is good.
