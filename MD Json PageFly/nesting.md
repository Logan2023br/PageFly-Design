## How the editor decides

Every element declares two patterns: which parents it may sit in, and which children it may hold.
A drop is allowed only when **both** agree. An element you can place inside a container is therefore
one the container accepts AND one that accepts that container as a parent. Either side saying no is a no.

Most elements inherit the default rule: they can sit almost anywhere, and they hold nothing.
Only containers override the second half.
